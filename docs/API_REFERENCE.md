# PromptLab API Reference

Version 0.1.0 · Base URL: `http://127.0.0.1:8000`

PromptLab is a REST API for storing, organizing and searching AI prompt templates. This reference covers all 11 endpoints. Interactive docs are also available at `/docs` (Swagger UI) while the server is running.

## Authentication

None. All endpoints are public. CORS allows all origins.
Authentication is planned and not implemented; do not expose this server publicly.

## Conventions

- Request and response bodies are JSON (`Content-Type: application/json`).
- IDs are UUID4 strings generated by the server.
- Timestamps are ISO 8601 in UTC with no timezone suffix, e.g. `2026-11-25T06:28:35.814657`.
- 204 responses have an empty body.
- Data is held in memory and is lost when the server restarts.
- There is no root endpoint; `GET /` returns 404 `{"detail": "Not Found"}`.
- In the examples, replace `{prompt_id}` and `{collection_id}` with real IDs returned by the create endpoints.

## Data models

### Prompt

| Field | Type | Required | Rules |
|---|---|---|---|
| id | string | server-set | UUID4 |
| title | string | yes | 1-200 chars |
| content | string | yes | min 1 char; may contain `{{variables}}` |
| description | string or null | no | max 500 chars |
| collection_id | string or null | no | must be an existing collection |
| created_at | datetime | server-set | never changes |
| updated_at | datetime | server-set | set on create, PUT and PATCH |

### Collection

| Field | Type | Required | Rules |
|---|---|---|---|
| id | string | server-set | UUID4 |
| name | string | yes | 1-100 chars |
| description | string or null | no | max 500 chars |
| created_at | datetime | server-set | never changes |

### How prompts relate to collections

A prompt belongs to at most one collection, through its `collection_id` field.
`collection_id` is optional: a prompt with `null` belongs to no collection.

- Add or move a prompt: set `collection_id` on POST, PUT or PATCH. The collection must exist (otherwise 400 "Collection not found").
- Remove a prompt from its collection: PATCH with `{"collection_id": null}`, or PUT without `collection_id`.
- List a collection's prompts: `GET /prompts?collection_id={collection_id}`.
- Deleting a collection also deletes every prompt in it.

### List responses

- PromptList: `{"prompts": [Prompt, ...], "total": <number of items>}`
- CollectionList: `{"collections": [Collection, ...], "total": <number of items>}`

### HealthResponse

`{"status": "healthy", "version": "0.1.0"}`

## Error format

Errors raised by the API code (`HTTPException`) have a string `detail`:

```json
{ "detail": "Prompt not found" }
```

Validation errors from Pydantic (422) have a list `detail`, one entry per invalid field. `loc` says where the problem is (`["body", "<field>"]`). Example from `POST /prompts` with `{"title": ""}` (the `ctx` and `url` keys are trimmed here):

```json
{
  "detail": [
    {
      "type": "string_too_short",
      "loc": ["body", "title"],
      "msg": "String should have at least 1 character",
      "input": ""
    },
    {
      "type": "missing",
      "loc": ["body", "content"],
      "msg": "Field required",
      "input": { "title": "" }
    }
  ]
}
```

Exact `detail` strings the API returns:

| detail | Status | When |
|---|---|---|
| `"Prompt not found"` | 404 | The prompt in the URL does not exist |
| `"Collection not found"` | 404 | The collection in the URL does not exist |
| `"Collection not found"` | 400 | A request body's `collection_id` does not exist |
| `"title cannot be null"` / `"content cannot be null"` | 422 | PATCH sends `title` or `content` as `null` |
| `"Not Found"` | 404 | The path does not match any endpoint |

## Endpoints

### Health

#### GET /health

Check that the server is running and see its version.

**Example request**

```bash
curl http://127.0.0.1:8000/health
```

```json

```

### Prompts

#### GET /prompts

List prompts, newest first (sorted by `created_at`). Optional filters can be combined; a prompt must match all of them.

**Query parameters**

| Name | Type | Description |
|---|---|---|
| collection_id | string | Only prompts in this collection (exact match). An unknown ID returns an empty list, not an error. |
| search | string | Case-insensitive text match on `title` or `description`. Does not search `content`. |

**Example request: all prompts**

```bash
curl http://127.0.0.1:8000/prompts
```

**Example response — 200 OK**

```json
{
  "prompts": [
    {
      "title": "Code review",
      "content": "Review this code and list bugs: {{code}}",
      "description": null,
      "collection_id": null,
      "id": "451d5adb-07a3-477c-97d2-cd49bc073dcf",
      "created_at": "2026-11-25T06:28:36.871176",
      "updated_at": "2026-11-25T06:28:36.871181"
    },
    {
      "title": "Summarize",
      "content": "Summarize this text in 3 bullet points: {{text}}",
      "description": "Quick summaries",
      "collection_id": "f890cc6a-1e46-4acf-ac9e-46ae5d52cbc0",
      "id": "81157ad5-cf6d-4651-97e6-f575ff97ba49",
      "created_at": "2026-11-25T06:28:35.814657",
      "updated_at": "2026-11-25T06:28:35.814661"
    }
  ],
  "total": 2
}
```

**Example request: search (case-insensitive)**

```bash
curl "http://127.0.0.1:8000/prompts?search=SUMM"
```

**Example response — 200 OK**

```json
{
  "prompts": [
    {
      "title": "Summarize",
      "content": "Summarize this text in 3 bullet points: {{text}}",
      "description": "Quick summaries",
      "collection_id": "f890cc6a-1e46-4acf-ac9e-46ae5d52cbc0",
      "id": "81157ad5-cf6d-4651-97e6-f575ff97ba49",
      "created_at": "2026-11-25T06:28:35.814657",
      "updated_at": "2026-11-25T06:28:35.814661"
    }
  ],
  "total": 1
}
```

**Example request: filter by collection**

```bash
curl "http://127.0.0.1:8000/prompts?collection_id={collection_id}"
```

Returns the same shape, containing only prompts in that collection. With no matches: `{"prompts": [], "total": 0}`.

**Errors:** none.

#### POST /prompts

Create a prompt. The server sets `id`, `created_at` and `updated_at`.

**Request body**

| Field | Type | Required | Rules |
|---|---|---|---|
| title | string | yes | 1-200 chars |
| content | string | yes | min 1 char |
| description | string or null | no | max 500 chars |
| collection_id | string or null | no | must be an existing collection |

**Example request**

```bash
curl -X POST http://127.0.0.1:8000/prompts \
  -H "Content-Type: application/json" \
  -d '{"title": "Summarize", "content": "Summarize this text in 3 bullet points: {{text}}", "description": "Quick summaries", "collection_id": "{collection_id}"}'
```

**Example response — 201 Created**

```json
{
  "title": "Summarize",
  "content": "Summarize this text in 3 bullet points: {{text}}",
  "description": "Quick summaries",
  "collection_id": "f890cc6a-1e46-4acf-ac9e-46ae5d52cbc0",
  "id": "81157ad5-cf6d-4651-97e6-f575ff97ba49",
  "created_at": "2026-11-25T06:28:35.814657",
  "updated_at": "2026-11-25T06:28:35.814661"
}
```
**Example request: prompt without a collection**

```bash
curl -X POST http://127.0.0.1:8000/prompts \
  -H "Content-Type: application/json" \
  -d '{"title": "Summarize", "content": "Summarize this text in 3 bullet points: {{text}}"}'
```

The response has `"description": null` and `"collection_id": null`.
To put the prompt in a collection, create the collection first (POST /collections) and use its `id`.

Optional fields that are left out come back as `null`.

**Errors**

| Status | When | Body |
|---|---|---|
| 400 | `collection_id` does not exist | `{"detail": "Collection not found"}` |
| 422 | Missing `title` or `content`, empty `title`, or a length rule broken | Pydantic list format (see Error format) |

#### PUT /prompts/{prompt_id}

Replace a prompt completely. `title` and `content` are required. Any optional field you leave out is set to `null`. `id` and `created_at` are kept; `updated_at` is set to now. To change only some fields, use PATCH.

**Path parameters**

| Name | Type | Description |
|---|---|---|
| prompt_id | string | ID of the prompt to replace |

**Request body:** same fields and rules as POST /prompts.

**Example request**

```bash
curl -X PUT http://127.0.0.1:8000/prompts/{prompt_id} \
  -H "Content-Type: application/json" \
  -d '{"title": "Code review (strict)", "content": "Review this code strictly and list every bug: {{code}}"}'
```

**Example response — 200 OK**

```json
{
  "title": "Code review (strict)",
  "content": "Review this code strictly and list every bug: {{code}}",
  "description": null,
  "collection_id": null,
  "id": "451d5adb-07a3-477c-97d2-cd49bc073dcf",
  "created_at": "2026-11-25T06:28:36.871176",
  "updated_at": "2026-11-25T06:28:37.096738"
}
```

**Errors**

| Status | When | Body |
|---|---|---|
| 404 | No prompt with this ID | `{"detail": "Prompt not found"}` |
| 400 | `collection_id` does not exist | `{"detail": "Collection not found"}` |
| 422 | `title` or `content` missing, or a rule broken | Pydantic list format |

Example 422: sending only `{"title": "Only title"}` returns:

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["body", "content"],
      "msg": "Field required",
      "input": { "title": "Only title" }
    }
  ]
}
```

#### PATCH /prompts/{prompt_id}

Update only the fields you send. Fields you leave out keep their current values. `updated_at` is set to now; `id` and `created_at` never change.

**Path parameters**

| Name | Type | Description |
|---|---|---|
| prompt_id | string | ID of the prompt to update |

**Request body** (all fields optional)

| Field | Type | Rules |
|---|---|---|
| title | string | 1-200 chars; cannot be null |
| content | string | min 1 char; cannot be null |
| description | string or null | max 500 chars; `null` clears it |
| collection_id | string or null | must exist; `null` removes the prompt from its collection |

**Example request**

```bash
curl -X PATCH http://127.0.0.1:8000/prompts/{prompt_id} \
  -H "Content-Type: application/json" \
  -d '{"description": "Short summaries for meeting notes"}'
```

**Example response — 200 OK**

```json
{
  "title": "Summarize",
  "content": "Summarize this text in 3 bullet points: {{text}}",
  "description": "Short summaries for meeting notes",
  "collection_id": "f890cc6a-1e46-4acf-ac9e-46ae5d52cbc0",
  "id": "81157ad5-cf6d-4651-97e6-f575ff97ba49",
  "created_at": "2026-11-25T06:28:35.814657",
  "updated_at": "2026-11-25T06:28:37.188869"
}
```

Only `description` and `updated_at` changed; every other field kept its value.

**Errors**

| Status | When | Body |
|---|---|---|
| 404 | No prompt with this ID | `{"detail": "Prompt not found"}` |
| 400 | `collection_id` does not exist | `{"detail": "Collection not found"}` |
| 422 | `title` or `content` sent as `null` | `{"detail": "title cannot be null"}` (or `content`) |
| 422 | A field breaks its rules (e.g. empty title) | Pydantic list format |

**Difference from PUT:** PUT replaces the whole prompt and requires `title` and `content`; any optional field left out becomes `null`. PATCH changes only what you send.

#### DELETE /prompts/{prompt_id}

Delete a prompt.

**Path parameters**

| Name | Type | Description |
|---|---|---|
| prompt_id | string | ID of the prompt to delete |

**Example request** (`-i` shows the status line)

```bash
curl -i -X DELETE http://127.0.0.1:8000/prompts/{prompt_id}
```

**Example response — 204 No Content**

```
HTTP/1.1 204 No Content
```

No response body.

**Errors**

| Status | When | Body |
|---|---|---|
| 404 | No prompt with this ID (including one already deleted) | `{"detail": "Prompt not found"}` |

#### DELETE /collections/{collection_id}

Delete a collection **and every prompt in it**. This cannot be undone.

**Path parameters**

| Name | Type | Description |
|---|---|---|
| collection_id | string | ID of the collection to delete |

**Example request**

```bash
curl -i -X DELETE http://127.0.0.1:8000/collections/{collection_id}
```

**Example response — 204 No Content**

```
HTTP/1.1 204 No Content
```

No response body. Afterwards, `GET /prompts/{prompt_id}` for any prompt that was in the collection returns 404 `{"detail": "Prompt not found"}`.

**Errors**

| Status | When | Body |
|---|---|---|
| 404 | No collection with this ID | `{"detail": "Collection not found"}` |
